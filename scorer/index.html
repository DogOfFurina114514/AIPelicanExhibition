AI 鹈鹕作品评分器

一个可以拖入 HTML 文件、自动分析美观性/简洁度/功能性的桌面小工具。

这是什么？

这是本站用于给每个 AI 生成的网页作品打分的工具。它不会「看」作品长什么样，而是通过分析 HTML 源码里的结构、样式、脚本，按照三个维度给出一组客观分数。所有作品页面上展示的评分，都是由这个程序生成的。

它是怎么打分的

程序读取 HTML 源码后，从三个独立维度逐项检查。每个维度满分 10 分，最终总分是三个维度的平均值，保留一位小数。

🎨

美观性

  • 布局系统：是否使用 Flex / Grid 等现代布局
  • 配色丰富度：颜色数量与层次
  • 现代 CSS 特性：变量、渐变、阴影、滤镜
  • 微交互：悬停、过渡、关键帧动画
  • 响应式设计与字体层级
✨

简洁度

  • 内联样式比例（越少越好）
  • !important 滥用程度
  • CSS 属性重复率
  • DOM 嵌套深度
  • 文件体积与空标签
  • 加分：CSS 变量统一管理、语义化标签
⚙️

功能性

  • 交互元素数量（按钮、输入框等）
  • 事件处理闭环
  • DOM 操作丰富度
  • 数据能力：网络、存储、Canvas/SVG
  • 键盘 / 触摸事件支持
  • 错误处理与函数结构

下载

两种方式任选其一：如果你装过 Python 可以直接跑源码，否则下载 Windows 独立程序双击即用。

🐍
scorer.py Python 源码 · 需要 pip install PySide6
💻
scorer.exe Windows 独立程序 · 双击即用 · 无需 Python

使用说明

  1. 下载 scorer.exe 或 scorer.py 并运行。
  2. 把任意 .html 文件拖进窗口（或者点右上角按钮选择文件）。
  3. 程序会立刻分析并显示三个维度的评分和总分。
  4. 每个维度下方会逐条列出加分/扣分的具体项，一眼看出分是怎么来的。

自己打包（可选）

如果你想自己从源码构建 Windows 独立程序，用 PyInstaller 一条命令即可。

pip install pyinstaller cd scorer pyinstaller --onefile --windowed --name scorer --clean --noconfirm scorer.py
